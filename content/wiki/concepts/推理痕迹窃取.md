## 定义

针对闭源 LLM API 的一类攻击：利用供应商返回给客户端的加密推理痕迹（chain-of-thought）块在同一生态内跨会话/用户/模型兼容的特性，把强模型的加密痕迹注入同供应商"防护更弱"的模型，迫使其明文输出推理内容——从而绕过反蒸馏保护、窃取专有模型的逐步推理。

## 关键信息

- **根源**（arXiv 2608.09867，2026-08）：供应商为保护知识产权而隐藏思维链，但推理痕迹以加密文本块形式返回客户端、由客户端随请求回传；这些块在供应商生态内完全可互换，形成架构级漏洞。
- **四大攻击向量**：
  - ① 反蒸馏绕过：无需直接越狱强模型，即可提取其推理（Anthropic、OpenAI、Google 上已验证）；
  - ② 隐私数据提取：从公开仓库抓取 315,320 个推理块，恢复 367 条 PII 与 182 个凭据（开发者常公开分享含加密块的会话日志而不自知）；
  - ③ 危险信息泄露：模型最终可见输出可安全拒绝恶意请求，但推理过程仍暴露危险信息；
  - ④ 隐形提示注入：把恶意载荷完全藏在加密块内，污染公开的智能体（agentic）部署。
- **防御方向**：负责任披露后，论文提出加密与系统级缓解方案；对依赖"客户端回传推理块"架构的供应商，需重新设计信任边界。
- **关联**：属于模型 API 安全与多智能体安全交汇的新兴攻击面；"隐形提示注入污染智能体部署"直接威胁 agent 生态。

## 定义

在线 IDE / Vibe coding 平台公司（2016 年创立，CEO Amjad Masad），通过浏览器内开发环境与 AI agent 让非技术人员也能构建软件；2026 年与 OpenAI 深度合作，是 GPT-5.6 Luna 的主要商业采用者。

## 关键信息

- **Free Mode**（2026-08-19）：由 GPT-5.6 Luna 驱动的默认订阅档位，Core（$20/月）与 Pro（$100/月）用户可先免费聊天/构思/跑简单任务，再动用订阅预算，缓解 token 焦虑；是"降低 AI 产品成本"趋势的代表产品。
- **智能路由**：Replit agent 判断任务需要更复杂模型时自动转路由，完成后"尽快回到 Free Mode"（AI 负责人 Michele Catasta 称"很多任务不需要前沿级智能"）。
- **与 OpenAI 关系**：2020 年就是 GPT-3 早期用户；双方称这是"未来多次联合发布的第一个"；CEO Sam Altman 称希望"任何能上网的人都能构建产品"。
- **背景**：OpenAI 2026-07-30 将 Luna API 价格下调 80%，使 Free Mode 在商业上可行。

# 摘要：Linear《How teams build》——2026 软件团队的 AI 使用实测数据

> 来源：Linear（Edition 01，Tim Qi），2026-08。原文见 `raw/01-articles/ai-news-2026-08-19-linear-ai-usage.md`

## 核心摘要

- **样本**：Linear 自家付费客户（12.7 万+活跃用户、13,300 名高管），观测 2024-06 至 2026-06。
- **采用率翻倍**：2026 上半年各职能 AI 功能活跃率翻倍以上——产品 12%→34%、工程 12%→30%、创始人 14%→30%、设计 6%→22%、GTM 5%→18%。
- **高管亲自上手**：201+ 人公司 CEO 活跃率 9%→36%（全报告最大增幅），CTO 11%→35%，说明高层在"用中学"。
- **规模无差异**：从初创到企业，AI 采用率约同步翻三倍，公司规模几乎不构成差异。
- **AI 创作近半 issue**：两年前 AI 创建的 issue 不足千分之一，2026 年已接近一半，按当前速度将很快超过人与集成之和。
- **非工程师开始写码**：产品经理提 PR 比例 3%→10%，设计师 1%→8%。
- **产出加速**：每工作区 PR 数量两年 +111%；接入编码 agent 的团队周 PR 21→65，未接入者 8→10，几乎全部增长来自 agent 侧。

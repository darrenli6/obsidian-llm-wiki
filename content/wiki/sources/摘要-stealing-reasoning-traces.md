# 摘要：论文——从闭源 LLM API 窃取推理痕迹（arXiv 2608.09867）

> 来源：arXiv 2608.09867（2026-08-10 提交）。原文见 `raw/01-articles/ai-news-2026-08-20-stealing-reasoning-traces.md`

## 核心摘要

- **背景**：主流 LLM 供应商为保护知识产权、限制信息泄露，隐藏模型的逐步推理（思维链）；推理痕迹不保存在服务端，而是作为加密文本块返回客户端，由客户端随后续请求回传。
- **架构漏洞**：这些加密块在同一供应商生态内跨会话、跨用户、跨模型完全兼容可互换；攻击者把强模型的加密推理痕迹注入同一供应商"防护更弱"的模型，即可迫使后者逐字明文输出推理内容——无需直接越狱强模型。
- **四个攻击向量**：① 绕过反蒸馏机制，提取闭源模型推理（已在 Anthropic、OpenAI、Google 上演示）；② 大规模隐私数据提取——从公开仓库抓取 315,320 个推理块，恢复 367 条个人身份信息（PII）与 182 个凭据；③ 暴露推理过程中隐藏的危险信息（即使模型最终可见输出安全地拒绝恶意请求）；④ 隐形提示注入——把恶意载荷完全藏在加密块内，污染公开的智能体部署。
- **缓解**：论文在负责任披露后提出加密与系统级缓解方案，以保护客户端推理。
